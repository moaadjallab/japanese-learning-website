# SPEC — Online Japanese Learning Platform (Version 1)

Create a modern, professional and responsive website for an online Japanese learning platform.

## PROJECT OBJECTIVE

The website is designed to promote and sell online Japanese language courses through monthly subscriptions.

The target audience is mainly:

- Arabic-speaking students, especially from Morocco and Gulf countries
- English-speaking students
- Students of all ages and all Japanese levels
- Complete beginners to advanced learners
- Students interested in JLPT, conversation, travel, studies, work and Japanese culture

IMPORTANT: This is VERSION 1 of the project. Do NOT create a complex LMS or student platform yet. For now, create a professional marketing and subscription website that presents the courses and allows users to subscribe and pay.

## LANGUAGES

The website interface must support:

- Arabic
- English

The website should have a language switcher: العربية | English

Arabic should use RTL layout. English should use LTR layout.

Japanese is the language being taught and should appear naturally in course content, examples, vocabulary, Japanese expressions and educational sections.

## DESIGN

Create a premium, modern Japanese-inspired visual identity.

The design should feel:

- Professional
- Clean
- Elegant
- Educational
- Trustworthy
- Modern
- Japanese-inspired without being overly stereotypical

Use subtle Japanese visual elements such as:

- Japanese typography
- Minimal Japanese patterns
- Sakura-inspired visual details
- Torii-inspired shapes only when appropriate
- Japanese red/white aesthetic used carefully
- Modern cards and clean layouts

Do not make the website look like an anime website. It should look like a serious professional online education business.

The website must be:

- Fully responsive
- Mobile-first
- Desktop compatible
- Tablet compatible
- Fast and clean
- Accessible
- SEO-friendly

## AUTHENTICATION AND FUTURE SCALABILITY

Although this is only the first version, structure the UI and code so that the platform can later become a full learning management system.

Future roles: Student, Teacher, Admin

Future features: Student dashboard, Video courses, Exercises, Quizzes, Progress tracking, Certificates, Live classes, Teacher dashboard, Multiple teachers, Admin dashboard

However, DO NOT implement these complex features in V1 unless necessary.

## FUTURE MULTI-TEACHER SUPPORT

The platform will initially have one main teacher. Later, other Japanese teachers should be able to join the platform. Therefore, avoid designing the brand around a single teacher's personal name. The brand should be independent and scalable.

## IMPORTANT UX PRINCIPLES

The website's primary conversion goal is: Visitor → Subscription

Every important page should have a clear CTA: "Start Learning" or "Subscribe Now"

The user should never be confused about:

- What the platform offers
- Who the courses are for
- What levels are available
- What each subscription includes
- How much it costs
- How to subscribe
- What happens after payment

Use clear spacing, strong visual hierarchy, modern cards, subtle animations and professional typography.

Avoid excessive animations.

The final result should look like a real professional Japanese online education startup, not a generic template.

Create all pages with consistent design, reusable components and a scalable structure.
